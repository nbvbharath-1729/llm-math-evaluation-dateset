# Data Collection Methodology

## Problem Selection
50 math problems selected across 10 topic areas, covering 
from standard competitive exam difficulty levels.
Distribution: 18 Easy, 20 Medium, 12 Hard.

## AI Response Collection
Each problem was submitted to three LLMs using an identical 
prompt:
"Solve the following math problem step by step, showing all 
your working clearly. State your final answer at the end. 
Use plain text only.
Problem: [question]"

Responses collected between 11 sept 2026 and 13 sept 2026.
Models used: GPT-4o (OpenAI), Claude (Anthropic), 
Gemini (Google).

## Evaluation Process
All 150 responses evaluated manually by a single human 
evaluator to ensure consistency. Each response scored 
independently without seeing other models' responses to 
the same question. Verified answers cross-checked using 
Wolfram Alpha before evaluation.

## Scoring
Three-dimensional rubric applied to each response.
Final Score calculated using weighted formula.
All evaluations include a written justification.
